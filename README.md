# Django Online Course Application

## Project Overview

The Django Online Course Application is a web-based learning platform that allows learners to explore courses, view lessons, and take assessments. This project implements an assessment feature that enables learners to answer exam questions, submit their responses, and view their results.

## Features

- Course details and lesson display
- Question and answer choice management
- Django Admin integration
- Online assessment and mock exam functionality
- Exam submission and result evaluation
- Display of exam scores and results
- Bootstrap-based course details interface

## Technologies Used

- Python
- Django
- HTML
- Bootstrap
- SQLite
- Git and GitHub

## Main Project Components

- `models.py` — Defines the Question, Choice, and Submission models.
- `admin.py` — Configures Django Admin and the required inline classes.
- `views.py` — Handles exam submission and result display.
- `urls.py` — Defines URL routes for the assessment features.
- `course_details_bootstrap.html` — Displays course information and related lessons.

## Project Objective

The objective of this project is to extend an online course application with assessment functionality, allowing learners to attempt mock exams and review their performance.

## Project Status

Development and testing of the required assessment features are in progress.
